# ModelBooster examples (deprecated)

ModelBooster is deprecated in v1.1; use ModelServing, ModelServer, and ModelRoute. Removal is no earlier than v1.5.

These examples are retained for existing users. For new deployments, follow the [ModelServing quick start](../../docs/kthena/docs/getting-started/quick-start.md#modelserving) or the complete [vLLM prefill-decode guide](../../docs/kthena/docs/user-guide/prefill-decode-disaggregation/modelserving-vllm-pd-disaggregation.md), including the matching ModelServer and ModelRoute resources.

See the [deprecation details](../../docs/kthena/docs/user-guide/model-deployment.md#modelbooster-deprecation) for the compatibility commitment. Upgrading to v1.1 does not require deleting existing ModelBooster resources.
